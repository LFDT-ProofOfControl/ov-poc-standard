# Sources, transformations and execution history

Mikhail Sergeev prepared this model, fixtures and export with AI-assisted
drafting and review. The motivating public source is
[Christopher Filkins's explicit-obligation comment](https://github.com/LFDT-ProofOfControl/ov-poc-standard/issues/173#issuecomment-6509031753).
The implementation's conflict policy is the contributor's candidate semantics;
it is not attributed to that comment's author or presented as an adopted rule.

## Frozen expectations and retained originals

The contributor's retained development history records a contract, handwritten
expected findings and premise declarations committed before the original
implementation and execution. Expected findings were not generated from the
model's outputs. That original private history and its execution receipts are
not published in this package, so its earlier timing and execution reports
cannot be independently established from this export alone.

The earlier raw files remain preserved by the contributor. The hashes and
environments in [EXECUTIONS.json](EXECUTIONS.json) are a public derived report
of those records, not the raw records or evidence of public availability.
The public `CONTRACT.md` is an editorial export of the same operative semantics;
it is not falsely identified as the original frozen contract bytes.

## Export changes

- `reconcile.py`: the module description removes a development-only source
  pointer. Imports and all function bytes are unchanged.
- `run_controls.py`: the module description points here; only the result
  envelope's schema and scope strings change inside the runner. Comparisons,
  calls, expected findings, case count and exit behavior are unchanged.
- `controls.json`: only the top-level schema label changes. All case inputs,
  expected findings, linked-assessment declarations and properties are unchanged.
- `premises.json`: byte-identical to the retained source.
- `CONTRACT.md`: operative inputs, findings and assessment-envelope sections
  are retained verbatim. Introduction and history/control-description prose
  are rewritten for a public reader.
- README, this provenance note, attribution, dated supplement and execution
  summary are public-facing wrappers. The Apache license text is copied from
  the existing public supplement and is unchanged.
- `results.json` is generated by the documented export recipe in an isolated
  directory containing only the outgoing package. It is new smoke evidence.
  Its case objects are compared with the retained original result; the
  historical raw result is not overwritten or silently relabelled.

The SHA-256 values in `SHA256SUMS` identify the outgoing bytes. They do not
authenticate authorship, execution time or truth. The recorded export source
pins bind the smoke run to these particular inputs and executable files.

## Meaning of the executions

The original implementer run and a separate review-environment run both
reported 18/18 comparisons PASS with matching output bytes. The latter
executed the submitted controls; it was not an independently designed suite.
A subsequent export smoke run verifies the documented relocated recipe.
All three executions concern the same synthetic cases.

No execution in this package reproduces the separate 13-case campaign or
Bjørn Vidar Hauge's external report. No private third-party archive is copied,
requested or audited here.
